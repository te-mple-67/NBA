# NBA Teams \& Players



Приложение для просмотра команд и игроков НБА.



## Технологии

- C# WinForms (.NET Framework)

- Balldontlie API

- Newtonsoft.Json



## Функционал

- Загрузка списка всех команд НБА

- Просмотр игроков выбранной команды

- Информация: имя, позиция, рост, вес, страна



## Как запустить

1. Открыть NBA.sln в Visual Studio

2. Нажать F5



## API

Используется [balldontlie API](https://balldontlie.io)

- GET v1teams — список команд

- GET v1players — игроки команды
